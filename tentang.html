Tentang KodeDasar

Website ini dibuat sebagai proyek akhir mata kuliah (UTS) Pemrograman Web I, Program Studi Teknik Informatika, Universitas Siber Asia.

Latar belakang

Banyak pemula berhenti belajar web bukan karena materinya sulit, melainkan karena penjelasan yang tersebar di banyak tempat dan memakai istilah yang membingungkan. KodeDasar dibuat untuk merapikan hal itu: satu tempat berisi materi dasar HTML dan CSS yang disusun berurutan, memakai bahasa sehari-hari, dan disertai contoh kode yang bisa langsung dicoba.

Seluruh halaman dibangun memakai HTML, CSS buatan sendiri, dan JavaScript tanpa framework maupun basis data, sehingga semua kode yang berjalan di sini adalah hasil pengerjaan kelompok.

Anggota kelompok

Empat orang dengan peran yang berbeda dalam pembuatan website ini.

Nama Anggota 1

UI/UX & CSS

Menyusun wireframe, memilih warna dan huruf, serta menulis seluruh berkas CSS.

Nama Anggota 2

Struktur HTML

Membangun kerangka semantik halaman beranda dan materi beserta isinya.

Nama Anggota 3

JavaScript

Membuat pencarian materi, penyaring galeri, dan penilaian kuis otomatis.

Nama Anggota 4

Uji Coba & Unggah

Menguji seluruh fungsi di beberapa perangkat lalu mengunggah website ke hosting.
