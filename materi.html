Referensi tag HTML

Kumpulan tag yang paling sering dipakai beserta contoh penulisannya. Ketik nama tag di kotak pencarian untuk menyaring daftar di bawah.

Teks

<h1> sampai <h6>

Menandai judul dan subjudul. <h1> adalah tingkat tertinggi dan sebaiknya hanya dipakai satu kali per halaman, lalu turun berurutan ke bawah. 

<h1>Judul Halaman</h1>
<h2>Subjudul</h2>
<h3>Bagian yang lebih kecil</h3>
Teks

<p>

Membungkus satu paragraf. Browser otomatis memberi jarak antarparagraf, jadi tidak perlu menambahkan baris kosong secara manual. 

<p>Halaman web dibangun dari elemen-elemen HTML.</p>
Teks

<strong>, <em>, <mark>, <small>

Memberi penekanan pada teks. <strong> untuk hal penting, <em> untuk penekanan lisan, <mark> untuk menyorot, dan <small> untuk keterangan tambahan. 

<p>Simpan file dengan ekstensi <strong>.html</strong>,
bukan <em>.txt</em>.</p>
Navigasi

<a>

Membuat tautan ke halaman lain, ke bagian tertentu dalam halaman yang sama, atau ke alamat email. Tujuan tautan ditulis pada atribut href. 

<a href="materi.html">Buka materi</a>
<a href="https://unsia.ac.id" target="_blank">Situs kampus</a>
Media

<img>

Menampilkan gambar. Atribut alt wajib diisi sebagai keterangan apabila gambar gagal dimuat sekaligus membantu pembaca layar. 

<img src="img/logo.png" alt="Logo KodeDasar">
Daftar

<ul>, <ol>, <li>

Membuat daftar. Gunakan <ul> bila urutan tidak penting dan <ol> bila urutannya bermakna, misalnya langkah-langkah. 

<ol>
  <li>Buat file index.html</li>
  <li>Tulis kerangka HTML</li>
  <li>Buka lewat browser</li>
</ol>
Tabel

<table>

Menyajikan data dalam baris dan kolom. Baris ditulis dengan <tr>, judul kolom dengan <th>, dan isi sel dengan <td>. 

<table>
  <tr><th>Nama</th><th>Nilai</th></tr>
  <tr><td>Rina</td><td>88</td></tr>
</table>
Form

<form> dan <input>

Menampung isian dari pengunjung. Jenis isian ditentukan lewat atribut type, misalnya text, email, radio, atau checkbox. 

<form>
  <label for="nama">Nama</label>
  <input type="text" id="nama" name="nama">
  <button type="submit">Kirim</button>
</form>
Form

<select> dan <textarea>

<select> menampilkan daftar pilihan yang dapat dibuka, sedangkan <textarea> dipakai untuk isian panjang beberapa baris. 

<select name="tingkat">
  <option value="pemula">Pemula</option>
  <option value="mahir">Mahir</option>
</select>

<textarea name="pesan" rows="4"></textarea>
Semantik

<header>, <nav>, <section>, <footer>

Tag semantik menjelaskan makna bagian halaman, bukan sekadar wadah kosong seperti <div>. Struktur jadi lebih mudah dibaca manusia maupun mesin pencari. 

<header>
  <nav>...</nav>
</header>
<main>
  <section>...</section>
</main>
<footer>...</footer>
Media

<video> dan <audio>

Menyisipkan video dan suara tanpa bantuan program tambahan. Tambahkan atribut controls supaya tombol putar dan pengatur volume ikut ditampilkan. 

<video src="media/intro.mp4" controls></video>
<audio src="media/materi.mp3" controls></audio>
CSS

Selector CSS

Selector menentukan elemen mana yang akan diberi gaya. Selector tag memilih berdasarkan nama tag, class diawali tanda titik, dan id diawali tanda pagar. 

p        { color: #333; }
.kartu   { padding: 20px; }
#header  { background: #fff; }

Tag yang dicari tidak ditemukan. Coba kata kunci lain.

Atribut yang sering dipakai

Atribut ditulis di dalam tag pembuka untuk memberi keterangan tambahan.

Tabel 1. Daftar atribut HTML yang umum digunakan.
Atribut Dipakai pada Kegunaan
href <a> Menentukan alamat tujuan tautan.
src <img>, <video>, <audio> Menentukan lokasi berkas yang ditampilkan.
alt <img> Teks pengganti bila gambar gagal dimuat.
class Hampir semua elemen Penanda kelompok elemen agar bisa diberi gaya lewat CSS.
id Hampir semua elemen Penanda unik, hanya boleh dipakai satu kali per halaman.
type <input>, <button> Menentukan jenis isian atau jenis tombol.
target <a> Mengatur tautan dibuka di tab baru bila diisi _blank.
